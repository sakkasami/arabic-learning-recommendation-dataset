# arabic-learning-recommendation-dataset
Dataset and code for Arabic learning-resource recommendation based on learner sentiment.
# BRAD-Edu: a semi-synthetic Arabic educational corpus for affect-aware recommendation

BRAD-Edu extends the BRAD corpus of Arabic book reviews (Elnagar and Einea, 2016) into a test bed for
educational recommender systems. It keeps the real opinions, ratings and reader histories of BRAD and adds
the learning variables that BRAD does not contain (resource difficulty, learner ability, success, score,
time on task, completion and frustration), generated by a declared model.

To our knowledge, no public corpus combines learner opinions, the affect they express, learner histories and
learning outcomes, in Arabic or for recommendation. BRAD-Edu is a first step in that direction, until real
Arabic e-learning corpora become available.

It was built for the article:

> S. Zrigui, S. Mallat, M. Mabrouk, I. Atanassova. *NFAR: A Neuro-Fuzzy Affective Recommender with Contextual
> Attention for Personalised Recommendation of Arabic Learning Resources from Learner Sentiment.* (submitted)

## What is real, derived and synthetic

| Type | Fields | Origin |
|---|---|---|
| Real | rating, review, user, book, order of the reviews | BRAD (texts not redistributed here, see below) |
| Derived | label, position, length, lexical diversity, difficulty cue; per book: rate of difficulty cues, mean rating, popularity | deterministic functions of the real data |
| Synthetic | `syn_*` fields | generated by `code/generator.py`, seed 2026 |

No synthetic field uses the output of any recommender or sentiment model. The affect that drives the
simulated frustration comes from the real star ratings.

## Rebuilding BRAD-Edu with the review texts

The review texts belong to BRAD and are not redistributed here. To rebuild the full corpus:

1. Download the unbalanced BRAD file (`unbalanced_reviews.tsv`) from https://github.com/elnagara/BRAD-Arabic-Dataset
   Note: in the distributed file the columns are `rating, review_id, user_id, book_id, review`.
2. Download LABR (`data/reviews.tsv`) from https://github.com/mohamedadaly/LABR
3. Run (Python 3, numpy, pandas):

```
python code/generator.py --input unbalanced_reviews.tsv --format brad --exclude reviews.tsv --out out
```

The output is identical to the released files (up to floating-point rounding), with the review text added.
Sensitivity variants: add `--rho 0` / `--rho 0.6` / `--w_aff 0.3` / `--w_aff 0.7`.

## Intended uses and limitations

- Next-item recommendation on real behaviour (the target is the real next book), with or without the review texts.
- Evaluation of sentiment-aware and pedagogical recommenders in a declared simulation.
- The learning variables are generated, not observed. In this model the expected gain of an interaction does
  not depend on difficulty; results that involve `syn_*` fields are simulation results and must be reported as such.
- Books are a proxy for learning resources.
